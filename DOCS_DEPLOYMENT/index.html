    📚 MkDocs Material Documentation Site Setup¶

    This repository includes a MkDocs Material documentation site that automatically publishes all markdown files as a beautiful, searchable website - publicly accessible even from this private repository.

    🌐 Deployment Options¶

    Option 1: GitHub Pages (Recommended)¶

    The easiest option - your site will be publicly accessible at https://YOUR_USERNAME.github.io/AgriTwin-GH/

    Setup Steps:¶

    1. Enable GitHub Pages:
    2. Go to your repository Settings → Pages
    3. Under "Source", select Deploy from a branch
    4. Select branch: gh-pages and folder: / (root)

    5. Click Save

    6. Update Repository URL:

    7. Edit mkdocs.yml and replace YOUR_USERNAME with your actual GitHub username

    8. Push Changes: 

      git add .
git commit -m "Add MkDocs documentation site"
git push origin main

    9. Automatic Deployment:

    10. The GitHub Action will automatically build and deploy your site
    11. Check the "Actions" tab to monitor the deployment

    12. Your site will be live at: https://YOUR_USERNAME.github.io/AgriTwin-GH/

    13. Share the URL:

    14. Anyone with the link can view your documentation
    15. The repository remains private, only the built site is public

    Option 2: Netlify (Alternative)¶

    For custom domains and advanced features:

    1. Create Netlify Account:
    2. Sign up at netlify.com

    3. Connect your GitHub account

    4. Deploy Site:

    5. Click "Add new site" → "Import an existing project"
    6. Select your repository
    7. Build command: mkdocs build
    8. Publish directory: site

    9. Click "Deploy"

    10. Set Up Secrets (for auto-deployment from GitHub Actions):

    11. Get your Netlify Auth Token from User Settings → Applications
    12. Get your Site ID from Site Settings → Site information

    13. Add to GitHub repository secrets:

      • NETLIFY_AUTH_TOKEN
      • NETLIFY_SITE_ID

    14. Uncomment Netlify deployment in .github/workflows/deploy-docs.yml

    15. Your site will be at: https://your-site-name.netlify.app

    🚀 Local Development¶

    Test your documentation site locally before deploying:

    1. Install Dependencies: 

      pip install -r requirements.txt

    2. Serve Locally: 

      mkdocs serve

    3. View at: http://127.0.0.1:8000

    4. Live Reload: Any changes to markdown files will automatically refresh in the browser

    📝 Adding New Documentation¶

    Automatic Discovery¶

    Simply add markdown files anywhere in your repository - MkDocs will automatically discover and include them in the site!

    Example locations: - docs/new-guide.md - docs/tutorials/tutorial-1.md - feature_demos/new-demo.md

    Manual Navigation (Optional)¶

    To customize the navigation order, edit the nav: section in mkdocs.yml:

    nav:
  - Home: index.md
  - Feature Demos:
    - Guide: feature_demos/FEATURE_DEMOS_GUIDE.md
  - Your New Section:
    - docs/your-page.md

    🎨 Customization¶

    Color Scheme¶

    Edit mkdocs.yml to change colors:

    theme:
  palette:
    primary: green  # Change to: blue, indigo, purple, pink, red, etc.
    accent: light-green

    Features¶

    Enable/disable features in mkdocs.yml:

    theme:
  features:
    - navigation.tabs
    - navigation.sections
    - search.suggest
    - content.code.copy

    See Material for MkDocs Features for more options.

    🔄 How It Works¶

    1. You add/edit markdown files in your repository
    2. Push to GitHub (git push)
    3. GitHub Actions automatically:
    4. Builds the MkDocs site
    5. Deploys to gh-pages branch (for GitHub Pages) or Netlify
    6. Your documentation is instantly updated at the public URL
    7. Scalable: New markdown files are automatically included

    🔗 Sharing the Link¶

    • Share your site URL with anyone
    • No GitHub account required to view
    • Your repository code remains private
    • Only the documentation website is public

    GitHub Pages URL: https://YOUR_USERNAME.github.io/AgriTwin-GH/
    Netlify URL: https://your-site-name.netlify.app

    🐛 Troubleshooting¶

    Site not deploying?¶

    • Check the "Actions" tab in GitHub for error messages
    • Ensure GitHub Pages is enabled in repository Settings → Pages
    • Verify the gh-pages branch exists

    Broken links?¶

    • Use relative paths: [Link](../path/to/file.md)
    • Check file paths are correct in mkdocs.yml

    Need help?¶

    • Check the workflow logs in the "Actions" tab
    • Ensure all paths in mkdocs.yml point to existing files
